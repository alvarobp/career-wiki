# Lesson 1: Hello AI Coding World: Install, Configure, Prompt

**Introduction**

- The lesson is part of a series titled "Principled AI Coding."
- Participants are introduced to AI coding with the goal of enhancing their coding skills to "superhuman" levels.

**Key Focus and Principle**

- The primary mission for this lesson is to set up AI tooling and explore fundamental AI coding patterns.
- Emphasis is placed on the KISS principle: "Keep It Simple, Stupid." It is highlighted as a guiding principle for both beginners and experienced engineers.

**Learning Methodology**

- Learners are encouraged to focus on simplicity to avoid overwhelm while learning.
- Whenever faced with distractions or confusion, participants are reminded to refocus on the lesson fundamentals.

**Setup Instructions**

- Participants are guided to install necessary tools and set up their environment to proceed with AI coding.
- A step-by-step demonstration is provided to validate the setup of various tools including Python, Git, and the AI coding assistant Aider.

**Coding Prompts and Usage of Aider**

- Participants run a series of commands using Aider to explore AI coding capabilities.
    - Example of basic AI prompts includes writing a simple Python print statement and executing it through Aider.
    - Further commands are demonstrated to modify code dynamically via natural language input.

**Practical Exercise**

- A practical exercise involves creating a word frequency counter using a transcript file.
- The lesson achieves results with just four commands in under a minute showcasing how quickly AI coding can deliver utility.

**Features and Commands**

- Aider supports commands that allow users to manage their code, correct mistakes quickly using an undo functionality, and engage in multiple file editing.
- The instructor highlights the importance of refining coding prompts for accuracy and efficiency.

**Conclusion and Next Steps**

- The lesson concludes with a recap of the skills acquired: basic AI coding prompt writing, utilization of AI coding tools, and a brief project.
- Upcoming lessons will delve into more complex commands, multi-file editing, and context management, allowing learners to manage real coding projects effectively.
- A reminder to ensure understanding of generated AI code and the outcomes desired to maximize the utility of AI coding assistants is reiterated.

**Encouragement**

- Participants are encouraged to practice what they've learned, check the resources available in their "loot box," and prepare for the next lesson on enhancing their AI coding capabilities.
