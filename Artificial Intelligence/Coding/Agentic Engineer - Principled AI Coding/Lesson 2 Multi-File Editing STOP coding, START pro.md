# Lesson 2: Multi-File Editing: STOP coding, START prompting

**Lesson Overview:**

- Title: "Principled AI Coding - Lesson 2"
- Focus: Moving from fundamentals to advanced AI coding, particularly with multi-file editing and efficient engineering practices using generative AI.

**Key Concepts Introduced:**

- **Big Three Bullseye Principle:** Importance of three components in AI coding:
    - Context
    - Model
    - Prompt
- The idea is to find the “bullseye” intersection where these elements align for optimal code output.

**Challenges in AI Coding:**

- Getting started may seem easy, but increasing productivity over time can be challenging if any one of the Big Three components is not well selected.

**Lesson Objectives:**

- Emphasizing the management of context in AI coding.
- Encourage learners to keep the Big Three principle in mind while writing code.

**Practical Application:**

1. Cloning the previous lesson's codebase to start the new coding lesson.
2. Setting up dependencies using a modern Python package manager (UV).
3. Guide to creating and modifying files efficiently:
    - Example provided for reading and modifying settings (.env files).
4. Modification of previous code from Lesson 1 to accommodate new functionality, such as passing transcription files as command-line arguments instead of hard-coded values.

**Coding Changes Introduced:**

- Introduction of a **blacklist** to filter out less useful words during transcript analysis.
- **OpenAI API integration** for summarization of transcripts and sentiment analysis.
- Discussion on additional coding techniques to manage file imports effectively to prevent code from breaking.

**Reviewing the Code Adjustments:**

- Encouragement to think of oneself as a **code reviewer** and **curator**, making sure AI-generated code meets project needs.
- Continuous modification over multiple files to maintain neatness and modularity in code.

**Upcoming Changes:**

- Highlighting forthcoming lessons on writing effective AI coding prompts to minimize hallucinations and enforce accuracy, leading to even faster coding.
- Practices involve specifying context, using models effectively, and crafting fine-tuned prompts.

**Concluding Remarks:**

- Reinforcement of AI coding as a method to enhance engineering efficiency, emphasizing the shift from manual coding to utilizing AI assistance in software development.
- Reminder for learners to focus on developing high-quality prompts that will serve as guides for AI coding assistants in their journey ahead.

**Final Notes:**

- Transition towards more complex coding tasks will be supported as learners become familiar with the tools and methodologies presented.
- Encouragement to leverage AI tools for automation and efficiency in coding practices.

**Next Lesson Preview:**

- Coding prompt structure will be improved to enable concise yet effective AI commands, focusing on the aid of the AI tools for rapid development.
